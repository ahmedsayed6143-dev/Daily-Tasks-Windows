# Daily Tasks for Windows 💻

A clean and easy-to-use **Daily Tasks** and **To-Do List** desktop application for Windows designed to help you organize your day, manage your schedule, and stay productive.

## ✨ Features (المميزات)
- **Add & Manage Tasks:** Easily create, edit, and delete daily tasks.
- **Task Status:** Mark tasks as completed to track your daily progress.
- **Desktop App for Windows:** Runs smoothly as a standalone Windows application with an available installer.
- **Clean Interface:** Simple and distraction-free user interface.

## 🛠️ Built With (التقنيات المستخدمة)
- **HTML & JavaScript**
- **Electron** (Desktop Application Framework)

## 🚀 How to Run (طريقة التشغيل)

### Option 1: Download Ready Installer (للمستخدمين)
1. Go to the **[Releases](https://github.com/ahmedsayed6143-dev/Daily-Tasks-Windows/releases/tag/v1.0.0)** section on the right.
2. Download and run the latest installer for Windows.

### Option 2: Run from Source Code (للمطورين)
1. Clone the repository:
   git clone https://github.com

2. Navigate to the project folder:
   cd Daily-Tasks-Windows

3. Install dependencies:
   npm install

4. Start the application:
   npm start
