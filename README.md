# Daily Tasks 📝

A clean and easy-to-use **Daily Tasks** and **To-Do List** application designed to help you organize your day, manage your schedule, and stay productive.

## ✨ Features (المميزات)
- **Add & Manage Tasks:** Easily create, edit, and delete daily tasks.
- **Task Status:** Mark tasks as completed to track your daily progress.
- **Clean Interface:** Simple and distraction-free user interface.
